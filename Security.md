# Security: panj

A static front-end with no backend, no accounts and no user data. The risks are supply chain, third-party media, and accidental exposure.

## Repository

- **Private** while building; public only at submission on Faizi's OK.
- No secrets in the repo. `.env*` is git-ignored. Nothing in this project needs a key until P7 (Mux playback IDs are public by design; Mux API tokens never enter the repo).

## Dependencies

- Video.js packages pinned to `10.3.0`; lockfile (`pnpm-lock.yaml`) committed.
- Only packages generated by `@videojs/cli` plus Vite/TypeScript. Adding a dependency needs a reason in the PR.
- Run `pnpm audit` before P7.

## Media and third parties

- Sample video comes from public Mux URLs over HTTPS (`stream.mux.com`, `image.mux.com`), loaded with `crossorigin`.
- No analytics, trackers or cookies. Mux Data is not enabled.
- If a Content Security Policy is added at P7, allow `media-src` and `img-src` for `stream.mux.com` / `image.mux.com` (see videojs.org CSP guide).

## Code

- Skin markup is static HTML from the package; the only interpolated values are constants in `apps/gallery/src/media.ts`. Never interpolate user input into `innerHTML`.
- No `eval`, no inline event-handler attributes.
